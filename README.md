Merhabalar bu java kod dizlimi bir bankanın atm sistemini simüle eder.Calışma şekli ise şöyledir:
Program sürekli çalışan bir ATM menüsüne sahiptir ve kullanıcı çıkış yapana kadar işlem almaya devam eder.
 Başlangıç bakiyesi 10.000 TL olarak başlanır.
- Kullanıcıya aşağıdaki menü sunulur:
  1. Bakiye görüntüleme
  2. Para yatırma
  3. Para çekme
  4. Çıkış
  kullanıcı bu işlemlerden istediğini secer.
- Kullanıcı seçimine göre ilgili işlem gerçekleştirilir.
- Para yatırma işleminde negatif veya sıfır değer kabul edilmez.
- Para çekme işleminde bakiye kontrolü yapılır.Ve ona göre cıktı verir.
- Bakiye yetersizse işlem gerçekleştirilmez.
- Geçersiz menü seçimlerinde hata mesajı gösterilir.
- Her işlemden sonra ana menü tekrar gösterilmelir.
- Kullanıcı çıkış seçeneğini seçtiğinde program sonlanır.Ve cıkış seceneğini yani 4. seceneği secmediği sürece program devam eder.
Kullanıcı 4. seceneği sectiğinde ise programdan cıktığı bilgisini cıktı yoluyla verir.
Programın calışma şekli böyledir,program farklı senaryolara karşı calışma testine tabi tutulmuştur, düzeltmler yapılmıştır ve program kendi yazımımdır.
Program do-while döngüsü kullanırak yazılmıştır,if-else ve switch-case komutlarından yararlanılmıştır.
Umarım güzel bir ornek ve yararlı  bir kod olmuştur.
